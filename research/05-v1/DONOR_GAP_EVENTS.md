# Donor gap-event ledger

## Scope

A donor lookup is not normal application development. It is allowed only after the current ten4seven package and AAPM extraction do not establish a viable generic contract. A successful lookup must be normalized into `@ten4seven/ui`, recorded in the component catalog and AI contract, and kept out of consumer runtime dependencies.
