Pill label for counts, categories and metadata. For record lifecycle use `StatusBadge` instead — it owns the status→colour mapping.

```jsx
<Badge variant="soft">22 modules</Badge>
<Badge variant="success" icon="check">Verified</Badge>
<Badge variant="soft" dot>Academy workspace</Badge>
<Badge variant="lime" overline>Lanjutkan belajar</Badge>
```

Semantic variants are a 10%-alpha wash of the status colour with the status colour as text — never a saturated fill, which would compete with buttons.
