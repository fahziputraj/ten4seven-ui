Tinted icon container — the AAPM way to tag a category or module without colouring a whole card.

```jsx
<IconTile icon="warehouse" tone="blue" />
<IconTile icon="kpi" tone="green" size="lg" />
<IconTile icon="ai" tone="orange" size="sm" />
```

One tone per category, reused everywhere that category appears. Tiles are decorative: the adjacent label carries the meaning.
