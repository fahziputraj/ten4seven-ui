Iconify surface

Ikon yang konsisten, dari Academy sampai Ebook.

Feature code memakai nama semantik. Registry memegang family, fallback, dan keputusan domain agar icon tidak blank atau berganti gaya tanpa alasan. Pola visual dapat mengikuti Minimal UI dan perilaku control mengikuti HeroUI, tetapi surface ikon tetap satu.
