## Reading rule

This matrix is an evidence classification for the generic ten4seven UI
system. It is not a production acceptance report for Farm, Farm Monitoring,
Operations/Sales/SCM, ERP, Academy, or native mobile applications.

`COMPOSED + PROVEN` means the generic contract is selected correctly and the
isolated reference or consumer proof demonstrates the interaction shape.
`NEW IMPLEMENTED + PROVEN` means a previously evidenced generic gap now has a
typed/public contract, canonical implementation, catalog/projection, reference
surface, and targeted proof. `READY` and `VERIFIED_READY` describe existing
canonical capabilities. `PRODUCT OWNED` and `NATIVE` are deliberate ownership
boundaries, not missing ten4seven work. `DEFERRED WITH EXPLICIT REASON` is used
only where the evidence does not justify a larger generic contract yet.

The separate `AAPM Adoption` column remains `UNVERIFIED` for production
journeys that were not run and accepted. That status does not make a proven
ten4seven library capability conditional.
