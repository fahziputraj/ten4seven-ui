Icon-only affordance. `label` is required — it is both the tooltip and the screen-reader name.

```jsx
<IconButton icon="edit" label="Edit row" size="sm" />
<IconButton icon="delete" label="Delete" tone="danger" />
<IconButton icon="sidebar" label="Collapse sidebar" variant="outline" />
```

Never use an icon button for a destructive action that has no confirmation step. Below 44px, keep icon buttons off mobile task screens.
