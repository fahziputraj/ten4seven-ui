Thin pill track. Lime on green/tinted surfaces, green on white.

```jsx
<Progress value={68} tone="lime" size="sm" track="hsl(var(--foreground-hsl) / .1)" label="Learning progress" />
<Progress value={91.8} tone="green" />
```

Always pair with the number as text — the bar is the shape of the number, not a replacement for it.
